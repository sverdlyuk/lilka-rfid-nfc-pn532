# PN532 — читання RFID/NFC-ключа для Лілки 🔑

Програма зчитує ідентифікатор (UID) безконтактної картки чи брелка стандарту 13.56 МГц (MIFARE Classic, MIFARE Ultralight, NTAG) через
модуль PN532 і показує його на екрані Лілки. Обмін — по I2C.

## ⚠️ Спершу перевір частоту ключа 📻

PN532 працює тільки на 13.56 МГц. Багато домофонних ключів — це 125 кГц EM-Marine (сині/чорні круглі «таблетки» і брелки). Такий ключ PN532 не побачить взагалі. Якщо UID не з'являється навіть впритул до антени — майже напевно ключ на 125 кГц, і для нього потрібен інший рідер.

## Вимоги до прошивки ⚙️

Потрібна збірка KeiraOS із модулем `i2c` у Lua реліз v2.6.11

## Підключення 🔌

**DIP-перемикачі PN532 — у режим I2C.** 
Модуль працює в трьох режимах. Для I2C лівий перемикач має бути переведений вгору, а правий залишитись внизу.

<img width="887" height="1280" alt="IMG_3364 — велике" src="https://github.com/user-attachments/assets/097b4205-9b57-4f5e-bb7a-a8328222b46e" />


| PN532 (I2C) | Лілка   |
| ----------- | ------- |
| VCC         | 3V3     |
| GND         | GND     |
| SDA         | Пін 13  |
| SCL         | Пін 12  |





## Протокол PN532 через I2C 📟

Кожна команда загортається у фрейм із двома контрольними сумами (по
довжині та по даних). Кожне читання по I2C починається зі статус-байта
готовності (`bit0 = 1` — дані готові), який код відкидає перед розбором.

## Керування 🎮

- **B** — вихід

## Діагностика 🩺

Якщо на екрані `Reader not found`, дивись рядок **`Bus scan:`**:

- **`0x24`** — PN532 видно на шині (дроти й DIP правильні).
- **`none`** — на шині ніхто не відповідає: перевір DIP (режим I2C) і
  дроти SDA/SCL/живлення.
